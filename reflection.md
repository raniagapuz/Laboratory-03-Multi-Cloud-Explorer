
# Mission Reflection

Completing the Multi-Cloud Explorer laboratory helped me understand that cloud computing is not limited to one provider. The cloud platform that impressed me the most was Amazon Web Services (AWS) because of its large selection of services and extensive global infrastructure. AWS provides many different technologies for computing, storage, networking, databases, security, analytics, and application development. I also found it interesting that AWS can support both small startups and large enterprise organizations.

AWS, Microsoft Azure, and Google Cloud have many similarities. All three platforms provide virtual machines, object storage, networking, identity management, databases, monitoring, security, containers, and artificial intelligence services. They also use similar infrastructure concepts such as regions and availability zones or zones. However, the providers use different product names and have different strengths and ecosystems.

Business requirements strongly influence cloud platform selection. An organization should consider its budget, existing infrastructure, technical skills, security requirements, compliance needs, application architecture, expected growth, and geographic requirements. For example, a company that already depends heavily on Microsoft technologies may benefit more from Azure, while an AI research organization may prefer Google Cloud because of its AI and machine learning capabilities.

Acting as a Cloud Solutions Consultant taught me that selecting a cloud provider is not simply about choosing the most popular platform. A cloud engineer must understand the client's actual problem and identify the services that provide the best technical and business solution. Different clients can therefore require different cloud platforms.

My GitHub Cloud Computing Portfolio has improved because I added a complete multi-cloud investigation with research documents, comparison tables, business recommendations, decision matrices, Linux investigation results, and screenshots. Organizing the laboratory using Markdown also helped me practice technical documentation and present cloud concepts in a professional format.
